# Contribuindo para o eco-link

Obrigado por considerar contribuir com este projeto!

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch para sua feature ou correção (`git checkout -b minha-feature`).
3. Faça commit das suas alterações (`git commit -m 'Minha contribuição'`).
4. Faça push para a branch (`git push origin minha-feature`).
5. Abra um Pull Request.

## Regras
- Sempre escreva testes para novas funcionalidades.
- Mantenha o padrão de código e siga as boas práticas.
- Descreva claramente o que foi feito na PR.

## Dúvidas
Abra uma issue caso tenha dúvidas ou sugestões!
